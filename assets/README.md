# assets/

Static app assets referenced from `app.json`.

| File                            | Used for                                    |
| ------------------------------- | ------------------------------------------- |
| `icon.png`                      | iOS app icon (`expo.icon`)                  |
| `splash-icon.png`               | splash screen image                         |
| `favicon.png`                   | web favicon (`expo.web.favicon`)            |
| `android-icon-foreground.png`   | Android adaptive icon — foreground layer    |
| `android-icon-background.png`   | Android adaptive icon — background layer    |
| `android-icon-monochrome.png`   | Android themed-icon monochrome layer        |

Currently the default Expo template art. Replace with SonicAccess branding
before a real build; keep the same filenames or update `app.json` to match.
